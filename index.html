Support Investigation Workflow

1. SIP Signaling

Inspect INVITE, response codes, registration, authentication, call setup and termination.

Example filter: sip

2. RTP Media

Check RTP streams, packet sequence, timing, payload type, jitter and media direction.

Example filter: rtp

3. Network Layer

Investigate TCP retransmissions, DNS behavior, routing, NAT and possible firewall-related symptoms.

Example: tcp.analysis.retransmission

4. API Integration

Validate HTTP status codes, authentication, authorization, request payloads and response data.

Example: 401 vs 403
